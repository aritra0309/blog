# Project Blog — Full Implementation Spec

A personal GitHub Pages site for writing about projects and other stuff. Home page
lists every post like a **build log** (commit-style entries), each post has a
category, and you can filter by category or search by keyword.

This version contains complete, working code for every file — a coding agent
should be able to create these files as-written, install two npm packages, and
have a working site. Content (posts, copy) is still yours to write; everything
structural/behavioral is fully specified.

---

## 1. Design direction (for context — already reflected in the CSS below)

Posts render like commit entries: a colored category dot, a short hash-style id
(`#a3f9`), date, title, excerpt, category tag — like scrolling through `git log`.
Paper-white background, ink-navy text, a mono face for meta/technical bits, a
sans face for reading. No gradients, no card shadows — hairline rules do the
separating.

| Token | Hex | Use |
|---|---|---|
| `--bg` | `#FAFAF7` | page background |
| `--ink` | `#1B1D23` | primary text |
| `--muted` | `#7A7E88` | meta text |
| `--line` | `#E4E1D8` | hairline borders |
| `--accent` | `#2B5D4C` | links, active states |
| `--accent-warm` | `#C1541C` | secondary accent |

Fonts: **IBM Plex Mono** (meta/nav/ids) + **IBM Plex Sans** (body), both free on
Google Fonts.

## 5. `build.js` (complete)

```javascript
const fs = require('fs');
const path = require('path');
const matter = require('gray-matter');
const { marked } = require('marked');
const crypto = require('crypto');

const POSTS_DIR = path.join(__dirname, 'posts');
const SITE_DIR = path.join(__dirname, 'site');
const DIST_DIR = path.join(__dirname, 'dist');

function shortId(slug) {
  return crypto.createHash('md5').update(slug).digest('hex').slice(0, 4);
}

function readTime(text) {
  const words = text.trim().split(/\s+/).filter(Boolean).length;
  return Math.max(1, Math.ceil(words / 200));
}

function formatDate(value) {
  if (value instanceof Date) return value.toISOString().slice(0, 10);
  return String(value);
}

function loadPosts() {
  const files = fs.readdirSync(POSTS_DIR).filter((f) => f.endsWith('.md'));
  const posts = files.map((file) => {
    const raw = fs.readFileSync(path.join(POSTS_DIR, file), 'utf8');
    const { data, content } = matter(raw);

    if (!data.title || !data.date || !data.category) {
      throw new Error(`Post ${file} is missing required front matter (title, date, category)`);
    }

    const slug = data.slug || file.replace(/\.md$/, '');
    return {
      id: shortId(slug),
      slug,
      title: data.title,
      date: formatDate(data.date),
      category: data.category,
      tags: data.tags || [],
      excerpt: data.excerpt || '',
      readTime: readTime(content),
      bodyHtml: marked.parse(content),
      url: `posts/${slug}.html`,
    };
  });
  return posts.sort((a, b) => (a.date < b.date ? 1 : -1));
}

function renderTemplate(template, vars) {
  return template.replace(/\{\{(\w+)\}\}/g, (_, key) => (key in vars ? vars[key] : ''));
}

function buildRelatedHtml(post, allPosts) {
  const related = allPosts
    .filter((p) => p.slug !== post.slug && p.category === post.category)
    .slice(0, 3);
  if (related.length === 0) return '';
  const items = related
    .map((p) => `<li><a href="${p.slug}.html">${p.title}</a> <span class="meta">${p.date}</span></li>`)
    .join('\n');
  return `<section class="related"><h3>Related entries</h3><ul>${items}</ul></section>`;
}

function main() {
  fs.rmSync(DIST_DIR, { recursive: true, force: true });
  fs.mkdirSync(path.join(DIST_DIR, 'posts'), { recursive: true });

  const posts = loadPosts();

  const indexData = posts.map(({ bodyHtml, ...meta }) => meta);
  fs.writeFileSync(path.join(DIST_DIR, 'posts.json'), JSON.stringify(indexData, null, 2));

  fs.copyFileSync(path.join(SITE_DIR, 'styles.css'), path.join(DIST_DIR, 'styles.css'));
  fs.copyFileSync(path.join(SITE_DIR, 'app.js'), path.join(DIST_DIR, 'app.js'));
  fs.copyFileSync(path.join(SITE_DIR, 'index.html'), path.join(DIST_DIR, 'index.html'));

  const postTemplate = fs.readFileSync(path.join(SITE_DIR, 'post-template.html'), 'utf8');
  posts.forEach((post) => {
    const html = renderTemplate(postTemplate, {
      title: post.title,
      date: post.date,
      category: post.category,
      readTime: post.readTime,
      id: post.id,
      body: post.bodyHtml,
      relatedEntries: buildRelatedHtml(post, posts),
    });
    fs.writeFileSync(path.join(DIST_DIR, 'posts', `${post.slug}.html`), html);
  });

  console.log(`Built ${posts.length} post(s) into dist/`);
}

main();
```

## 8. `site/app.js` (complete)

```javascript
let allPosts = [];
let activeCategory = 'all';
let searchQuery = '';
let debounceTimer = null;

const categoryColors = ['#2B5D4C', '#C1541C', '#3C5B8C', '#8A5A2B', '#6B4E8C'];
const categoryColorMap = new Map();

function colorFor(category) {
  if (!categoryColorMap.has(category)) {
    categoryColorMap.set(category, categoryColors[categoryColorMap.size % categoryColors.length]);
  }
  return categoryColorMap.get(category);
}

function renderPills(categories) {
  const container = document.getElementById('categoryPills');
  const all = ['all', ...categories];
  container.innerHTML = all
    .map(
      (cat) => `
    <button class="pill ${cat === activeCategory ? 'active' : ''}" data-category="${cat}">
      ${cat === 'all' ? 'All' : cat}
    </button>`
    )
    .join('');

  container.querySelectorAll('.pill').forEach((btn) => {
    btn.addEventListener('click', () => {
      activeCategory = btn.dataset.category;
      renderPills(categories);
      renderEntries();
    });
  });
}

function matchesSearch(post, query) {
  if (!query) return true;
  const haystack = `${post.title} ${post.excerpt} ${post.tags.join(' ')}`.toLowerCase();
  return haystack.includes(query.toLowerCase());
}

function renderEntries() {
  const list = document.getElementById('entries');
  const emptyState = document.getElementById('emptyState');
  const filtered = allPosts.filter(
    (p) => (activeCategory === 'all' || p.category === activeCategory) && matchesSearch(p, searchQuery)
  );

  if (filtered.length === 0) {
    list.innerHTML = '';
    emptyState.hidden = false;
    return;
  }
  emptyState.hidden = true;

  list.innerHTML = filtered
    .map(
      (p) => `
    <li class="entry">
      <a href="${p.url}">
        <span class="dot" style="background:${colorFor(p.category)}"></span>
        <span class="id">#${p.id}</span>
        <span class="date">${p.date}</span>
        <span class="title">${p.title}</span>
        <span class="excerpt">${p.excerpt}</span>
        <span class="tag">${p.category}</span>
      </a>
    </li>`
    )
    .join('');
}

async function init() {
  const res = await fetch('posts.json');
  allPosts = await res.json();

  const categories = [...new Set(allPosts.map((p) => p.category))];
  renderPills(categories);
  renderEntries();

  document.getElementById('search').addEventListener('input', (e) => {
    clearTimeout(debounceTimer);
    debounceTimer = setTimeout(() => {
      searchQuery = e.target.value;
      renderEntries();
    }, 150);
  });
}

init();
```

## 10. `.github/workflows/deploy.yml` (complete)

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

After pushing this, go to **repo Settings → Pages → Build and deployment → Source**
and set it to **GitHub Actions**.

## 12. Build order for the agent

1. Create the file structure above; run `npm install`.
2. Add 2–3 sample posts (section 11) to `/posts/`.
3. Create `build.js`, `site/index.html`, `site/post-template.html`,
   `site/styles.css`, `site/app.js` exactly as written above.
4. Run `npm run build`, then `npm run serve`, open the printed localhost URL,
   confirm: entries list, category pills filter, search filters, clicking an
   entry opens its post page, "related entries" shows on post pages.
5. Add `.github/workflows/deploy.yml`, push to `main`.
6. Set repo Pages source to "GitHub Actions" (one-time setting).
7. To add a post later: drop a new `.md` file in `/posts/`, push — it rebuilds
   and redeploys automatically.

## 13. Known extension points (not required, but easy to add later)

- **Tag page / multi-tag filtering**: currently only `category` is filterable;
  `tags` exist in the data but aren't wired to a UI control yet.
- **RSS feed**: generate an `rss.xml` in `build.js` from the same `posts` array.
- **Syntax highlighting**: swap `marked.parse` for `marked` + `highlight.js`
  if code blocks need coloring.
- **Dark mode**: add a `[data-theme="dark"]` variant of the CSS variables and a
  toggle button; not in scope above to keep the first version shippable.
